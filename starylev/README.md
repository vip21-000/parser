# Stary Lev Publishing Parser

Парсер каталогу товарів із сайту «Видавництва Старого Лева».

## Що збирає проєкт
Скрипт успішно зібрав масив даних із **4775 позицій** (станом на 23.10.2026) книжкової продукції видавництва.

### Колонки (Структура даних)
* title - Назва книги.
* author - Автор (або автори) твору.
* price - Актуальна ціна.
* book_url - Пряме посилання на сторінку товару.
* in_stock - Статус наявності (чи є в продажу).

## Що було найскладнішим
* **Пагінація та структура каталогу:** Обробка великої кількості сторінок та коректне збирання посилань без дублювання.
* **Очищення даних:** Фільтрація зайвих пробілів, символів переносу рядків та обробка випадків, 
коли певні поля (наприклад, ціна) були відсутні або мали нестандартну верстку.

## Етика вебсканування
Проєкт розроблений з дотриманням правил ввічливого скрейпінгу:
1. **Перевірка robots.txt:** Перед запуском було проаналізовано дозвільні правила сайту.
2. **Паузи між запитами (Rate Limiting):** Додано штучну затримку (time.sleep) між запитами до серверів видавництва, 
щоб не створювати надмірного навантаження та уникнути блокування IP-адреси.
